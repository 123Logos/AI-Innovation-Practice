# 前端设计守则（FRONTEND DESIGN GUIDELINES）

- 版本：v1.1（2026-11-09 第二轮：老板第 5 轮裁定入账 + 批次编号权威移交给 `docs/ROADMAP.md`）
- 适用范围：`frontend/src/**` 的一切用户可见物，以及**任何会出现在用户屏幕上的后端字符串**（错误信封的 `message`、校验提示、AI 文案）。
- 状态：**规范文档**。§9 逐条标了哪些已有机械闸、哪些目前只靠评审——没有闸的条款我不假装它被遵守。
- 与 `AGENTS.md` 的关系：本文件优先级低于 `AGENTS.md`，高于 `docs/DEVELOPMENT.md`；它不新增任何"设计愿景"，只把**已经在代码里成立的做法**和**老板已经下过的裁定**收敛成可判定的条款。每条都带今天的违例（§10）或既有实现（file:line），凭空立不起的规则不写。**批次编号与顺序的唯一来源是 `docs/ROADMAP.md`：本文件定义判据，不定义批次。**

## 1. 文案（C = Copy）

| 编号 | 规则 | 怎么算违反（判据） | 今天的状态 |
|---|---|---|---|
| **C1** | 用户可见文本**严禁 emoji**，包括用作图标的 ASCII 符号（`✨ 💡 ✓ ✗ ★ ⚠ ← ↑ ↓ ↺ ✦`）。要图标就用 SVG/字体图标，且 `aria-hidden="true"` + 相邻有文字标签。 | 一条正则扫描模板与字符串常量（§9 G1），命中即红。 | **违例 6 处**：`StylePanel.vue:339/350/354`、`AppTopBar.vue`、`JobCreateView.vue:264/380`；伪图标另计（`←` 5 个返回链接、`↑↓` 排序、`↺`）。 |
| **C2** | **严禁开发者黑话**上屏：服务商名、`Key`/`token`/`API`/`JSON`/`JWT`、`提示词`/`模型`/`非流式`/`上游`/`额度`/`后端在跑`、状态码数字。必须说人话时，说「谁来用这把尺子/花的是你的用量」这类**用户视角的因果**。唯一豁免：用户必须亲手去某个界面拿凭据时，可以出现那个界面里的原词（如他自己在「AI 设置」里粘贴的字段名）。 | 违例词表 + 扫描（§9 G1），豁免用行内标记。 | **违例密集**：`AppTopBar.vue:329/604/615/621`（DeepSeek API Key、`sk-……`、`<code>deepseek-flash</code>`、非流式）、`stores/job.ts:545/547/549/599/603/613`、`JobCreateView.vue`、`PolishSettingsDialog.vue:100`、`api/client.ts:333`。 |
| **C3** | 每一句失败提示必须**要么给出用户修得动的下一步，要么明说没有下一步**。「请求参数校验失败。」「请稍后重试。」这类无主语无动作的句子不许单独出现。 | 每个错误分支的文案常量必须命中「动作动词表」或「无可为表」之一（§9 G3）；今天的做法是人读。 | 违例：`app/main.py:212`（422 → 「请求参数校验失败。」）、`app/api/v1/jobs.py:62-65`（502 直显「被服务端的 token 上限切断了」）。 |
| **C4** | **绝不静默降级、绝不静默截断**。系统替用户做了任何减损（截尾、回落模板、跳过某段、少处理几条），必须在同屏说出来，并说清是自动的还是他选的。依据是老板 2026-11-04/11-08 两次原话（`ADR-009:24`、`ADR-013:381`）。 | 任何返回被减损的响应必须带一个可见标记位；前端不许把它吞掉。 | **已落地（`ADR-018`，批次 B9）**：润色不再砍尾，改为「目标字数 + 超出多少字」的可见标注（`app/schemas/resume.py` 的 `target_words` / `over_limit_by`），减字动作交回用户；唯一还会减字的是**响应契约** 1200/600——`app/schemas/resume.py::clamp_to_polish_contract` 做段级截断并标 `truncated=true`，其余段照常返回、不再整单 502。`tests/test_resume_ai_copywriting.py` 里那两条当时把砍尾钉成契约的用例已按裁定**改写方向**，不是删除。 |
| **C5** | 界面不解释技术构成：权重、归一分母、计数、版本号一律不上屏；但**「用户修得动的失败原因」必须分句保留、不许合并**（`ADR-013:608-610/784-785`，`stores/job.ts:558-569`）。 | 新增解释性文案要回答「这句话能不能变成用户的动作」；`weight_sum_used`/`*_version`/`candidate_pairs` 出现在模板即红。 | 合规（有注释 + `stores/job.ts:579` 裁定）。 |
| **C6** | 同一类产品状态**只允许一套机制**：提示只走一个 toast/内联反馈组件，确认只走一个自绘弹层。**禁用 `window.confirm` / `window.alert`**。 | ESLint `no-restricted-globals`（§9 G2）。 | **违例 6 处已清零**（批次 F1b，PR #21，2026-11-10）：`AppTopBar.vue` 三处（删除档案 / 去回收站前的未保存拦截 / 保存失败的 alert）、`StylePanel.vue`（生成前）、`stores/resume.ts`（切换前——这一处没有模板可渲染，所以弹窗状态必须全局）、`RecycleBinView.vue`（彻底删除）全部改走同一个 `stores/dialog.ts` + `components/ConfirmDialog.vue`，形态照 `JobDetailView.vue` 的先例。**同一产品两种做法**这一格从此收口。 |

## 3. 动效与加载（M）

| 编号 | 规则 | 判据 | 现状 |
|---|---|---|---|
| **M1** | 内容区的进入/退出**不许硬切闪现**：统一「淡入淡出 + 微位移」，位移 ≤ 8px，时长与缓动**必须取自令牌**，不许写死数字。 | 模板里出现裸 `transition:`/`animation:` 字面量即红；只能用 `var(--motion-*)`。 | **✅ 已落（批次 F4 第一片）**：令牌层先建（`--motion-fast/base/slow/pulse/ease/shift`，时长取自存量的 `.12s`/`.15s`，位移 6px），5 处硬编码过渡（顶栏两个箭头、工作区切换器箭头、润色弹窗、主题面板）全部改成令牌；全站唯一一份 `.ui-fade` / `.ui-fade-down` 接在**页面切换**（`RouterView` + `out-in`，时长压到 `--motion-fast`，因为 out-in 是退+进两段）、**两个抽屉**、**工作区 Popover**、**确认弹窗**、**AI 设置弹窗**上。判据在 `src/__tests__/motionGuards.spec.ts`（源码扫描，探针验过会红）。真浏览器 CDP 采样复核过进入与退出都在跑：Popover `.396 → 1`、抽屉 `.227 → 1`、退出 `.607 → 移除`，页面切换途中 `.314`。 |
| **M2** | 异步内容必须**先占位后填充**：骨架屏（或等高的占位块）+ 固定最小高度托底，尺寸取该区块稳定态的实测值，不许凭感觉写 `min-height`。 | 每个「加载后才出现内容」的容器必须有 `min-height` 令牌或骨架组件；jsdom 测不了视觉，但结构可测。 | **✅ 已落（批次 F4 第二片）**：`components/SkeletonList.vue` 一个组件，六个加载点全部接入（简历列表、岗位列表、岗位详情、岗位回收站、简历回收站、简历表单），原来那六句「正在加载…」一个字没改，挪进 `role="status"` + `aria-busy="true"` 容器里读屏可见的那一行。**高度是量出来的**：岗位卡片 158px(1280)/187px(375)、岗位详情前三块 229/167/331 与 377/200/508、回收站行 71 与 140/120、简历行 40、表单前三段 311/84/68 与 311/68/68，全部由 CDP 在稳定态量得并写在调用点注释里。拖慢网络复测：骨架块高与稳定态**逐块相等**（岗位列表 187×4 / 158×4，详情首块 377 / 229），数据到达时不跳。托底由这些等高块自己承担，没有另写一个猜出来的 `min-height`。 |
| **M3** | **动效不许掩盖状态不确定**：加载中、失败、空态三种必须各自可读；`prefers-reduced-motion` 下降级为无位移（可保留淡入）。 | 媒体查询存在且被 skeleton/transition 共用一个开关。 | **✅ 已落（批次 F4 第一片）**：开关只有 `styles.css` 一处——`--motion-shift: 0px` + `--skeleton-pulse: none`，时长不动（M3 允许保留淡入）。过渡与骨架因此共用同一组令牌，组件里**不许**再各写一个 `prefers-reduced-motion` 分支（源码扫描钉住，只看 `<style>` 段，注释里解释一句不算）。CDP `Emulation.setEmulatedMedia` 实测：减弱动效下位移 `matrix(1,0,0,1,0,0)`、`--skeleton-pulse: none`，而淡入仍在（途中 opacity `.260`）。三种状态各自可读：加载中是骨架 + 读屏文案，失败与空态仍是原来那两句可见文字，没有被骨架吞掉。 |
| **M4** | 页面内不许出现「动画驱动的功能」：任何数据正确性判断不许等动画结束再执行。 | 逻辑里不许出现 `setTimeout(…)` 与过渡时长耦合。 | 现状未见耦合（`DRAFT_WRITE_DELAY=400ms` 是本地草稿写入节流，属 debounce 不是动效）。 |

## 4. 布局与导航（L）

| 编号 | 规则 | 判据 | 现状 |
|---|---|---|---|
| **L1** | **一个布局，一处定义**。`app-shell` + 顶栏这类外框不许在每个视图里复制；由路由的嵌套布局承担。 | 视图里出现第二处 `<AppTopBar />` 手工摆放即红（今天 7 处：`ResumeEditorView.vue`、`JobBoardView.vue`、`JobCreateView.vue`、`JobDetailView.vue`、`RecycleBinView.vue`、`JobTrashView.vue` …）。 | **✅ 已收口（批次 F2，PR #24）**：外框与顶栏只在 `components/AppLayout.vue` 一处，6 个视图各自的 `app-shell` 与 `<AppTopBar />` 已删。`git diff -w` 复核过：每个视图的真实改动恰好是那 6 行，diff 里其余两千多行全是缩进。左边那 6 个视图行号锚点随本批失效，本列不再维护它们。 |
