# ADR-014：AGENTS.md §3.2 冻结清单全面解除

## 1. 背景

`AGENTS.md` §3.2 挂了九类功能（模拟面试、人岗匹配与批量下载、AI 爬虫采集、标准化题库测评、AI 用户画像、行业标杆人物库、教师端学情看板、真实外部 AI 服务、Redis/ARQ/Celery/S3/WebRTC/小程序），前置条件是「简历切片被 5 名以上真实用户验证」，在此之前**一行实现代码都不许写**。

时间线（按时点记录，不追改）：

| 日期 | 事件 |
|---|---|
| 2026-11-04 | 第一个例外：BYOK 接入真实 DeepSeek（ADR-009），只覆盖「生成简历的文案润色」。 |
| 2026-11-05 | 第二个例外：「企业需求自动解析」中的 JD 技能提取（ADR-011），并**明文免除**了「5 名用户」这一前置对它的门槛，同时强调「未免除上列任何其余冻结项」。 |
| 2026-11-07 | 5 名真实用户测试完成（另一套库，数据已归档）。 |
| 2026-11-08 | 人岗匹配（ADR-013）作为第三个例外开工；同日老板宣布 **10 名用户目标达标、「限制解除」**，在我追问后第 8 点定为**「全面解冻」**。 |

## 2. 决策

**§3.2 那张清单作为「不许开工」的禁令，自 2026-11-08 起整体作废。** 上面时间线里三个逐项例外不再是「例外」——它们是同一件事的三次提前开工。

`AGENTS.md` §3.2 的清单文字**保留**，但改成状态表并注明由本 ADR 解除，理由见 §4 的「不删清单」。

**仍然有效的三道闸，本 ADR 一道都不动**，这一点要说白：

1. **§4.6 ADR 闸门**：新增依赖、新表、接入外部服务、分层变更、范围变更，仍必须先写 ADR。解冻解除的是「这件事能不能做」，不是「做之前要不要留痕」。
2. **BYOK 白名单逐条批准**：`X-DeepSeek-Key` 每加一条 URL 需要老板**逐条书面同意**（他 2026-11-07 的原话），且我的可辩护版本必须是**路由表论证**（这条 URL 真的把请求转给 DeepSeek 吗）。这条是安全边界，不在 §3.2 的清单里，也不因全面解冻而放松。
3. **§4.4/§4.5/§6 的验证闸门**：测试原文、CI 全绿、真浏览器实测，一条不少。

## 3. 后果

- 批次计划里原先标「需逐项书面解冻」的 **B9（测评与画像）/ B10b（批量下载与审计）/ B11a（文本模拟面试）/ B11b（语音与转写）** 不再需要逐封批准信；改为**各写一份 ADR**（它们都要动新表或新依赖，本来也绕不开 §4.6）。
- 语音/转写（B11b）的原约束：「接语音必然引入**新外部供应商 + 新依赖 + BYOK 或后端凭证的新注入面**，ADR 里要写报价与降级路径」。
  **2026-11-14 事实更正（老板核实）**：DeepSeek **提供整段 ASR（不支持流式，单次 ≤120 秒）与 TTS**，
  所以「必须第二家供应商」这半句**作废**；仍是同一把 BYOK Key、同一套凭据生命周期，
  要扩的只有白名单里 `/v1/tools/asr` 与 `/v1/tools/tts` 两条 URL（属 §2 第 2 条的逐条书面同意，
  本轮只登记、不实现）。**「BYOK 注入面会扩张」「ADR 要写降级路径」两半仍然成立**：
  ASR 失败降级为手动输入、TTS 失败降级为纯文字、音频转写完毕立即删除（不入库、不存盘），
  口径记在 `ADR-022`「后续 B11b 的口径」与 `ROADMAP.md` §1 B11b 行。
- Redis / Celery / S3 / WebRTC 解除的是**禁令**，不是**必要性**。当前所有链路仍是同步 + 单库 + 应用时钟；引入任何一件都要单独 ADR，且要先说清「哪条已验证的行为因为它才成立」。
- 历史文档（ADR-009/011/013 里「仍在冻结之列」那几句）**不改写**：那是当时的时点真相。本文是唯一生效的解除记录。

## 4. 替代方案

- **(a) 继续逐项批准**（ADR-011 的老路子）。否决：老板已明确「全面解冻」，再逐项问一遍是把同一个决定重复外包。
- **(b) 把 §3.2 那张清单整段删掉**。否决：删掉之后，「哪些东西曾经被认为需要提前验证」这条判断线索就没了，而它正是本仓库用来抵抗「过度设计」的那段病史。清单留着当**墓碑**，只在旁边写明已解除。
- **(c) 只解除「用户数门槛」，保留清单本身的禁令**。这是我一开始的保守读法（ADR-011 那句「未免除上列任何其余冻结项」在前），老板第 8 点直接推翻了它，所以本 ADR 的存在本身就是这次澄清的结果。
